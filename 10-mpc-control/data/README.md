# Track waypoints

Part of [10 - MPC Control](../README.md).

| File | Contents |
|---|---|
| `lake_track_waypoints.csv` | Header `x,y` and 70 waypoints of the lake track in the Udacity simulator. |

Provided with the Udacity starter material, which notes that the file may not be completely in sync with the simulator. No code in this project reads it; it can be used for offline experiments such as fitting polynomials to the track. The controller uses the waypoints that the simulator sends at run time.
