# Output images

Result of the lane-finding pipeline (`main.py` in image mode) on the eight Udacity test images `straight_lines1/2.jpg` and `test1` to `test6.jpg`. Part of [04 - Advanced Lane Finding](../README.md).

Each image shows the detected lane area on the undistorted road image, thumbnails of the binary image, the bird's-eye view and the fitted lane lines, and the estimated curvature radius and offset from the lane centre. Running `main.py` writes new results to this folder under the same names, overwriting these files.
