# Trained HOG + SVM artefacts

Outputs of `train.py`, loaded by `main_hog.py`. Part of [05 - Vehicle Detection](../README.md).

| File | Contents |
|---|---|
| `svm_trained.pickle` | Trained scikit-learn `LinearSVC` classifier (car versus non-car). |
| `feature_scaler.pickle` | The fitted `StandardScaler` for the feature vectors. |
| `feat_extraction_params.pickle` | The feature-extraction parameter dictionary used for training (the same values as `feat_extraction_params` in `config.py`). |

These are pickled Python objects: they are sensitive to the scikit-learn version and should only be loaded from a source you trust. They are regenerated by `python train.py`, which needs the training images configured in `config.py`.
